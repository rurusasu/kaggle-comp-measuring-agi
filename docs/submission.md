# Measuring Progress Toward AGI - Cognitive Abilities - Submission Format

## Submission Type

This is a Hackathon competition. Submissions are made via Kaggle Writeups.

## Required Components

A valid submission must contain:

1. **Kaggle Writeup** - Your project report (max 1,500 words)
   - Must include a title, subtitle, and detailed analysis
   - Must select a Track (Learning, Metacognition, Attention, Executive Functions, or Social Cognition)
2. **Kaggle Benchmark [mandatory]** - Created with the kaggle-benchmarks SDK, linked as a project attachment
3. **Cover Image [mandatory]** - Required to submit your Writeup
4. **Public Project Link [mandatory]** - URL to your benchmark

## Optional Components

- Media Gallery (images/videos)
- Public Notebook

## How to Submit

1. Create a new Writeup via the "New Writeup" button on the Writeups tab
2. Create your Kaggle Benchmark with underlying tasks using the kaggle-benchmarks SDK
3. Link the benchmark in the writeup as a project link under "Attachments" > "Add a link"
4. Save your Writeup and click the "Submit" button in the top right corner

## Important Notes

- **Your final Submission must be made prior to the deadline.** Any un-submitted or draft Writeups by the competition deadline will not be considered by the Judges.
- If you attach a private Kaggle Resource to your public Kaggle Writeup, your private Resource will automatically be made public after the deadline.
- Tasks and benchmark should all be set to private during the competition. After the submission deadline, all tasks and benchmarks are published publicly.
- Upon joining the hackathon, your Kaggle account will be provisioned with extra quota ($50/day, $500/month) to run the AI models for your benchmark.

## Submission Limits

For Hackathons, each Team may submit one (1) Submission only.
